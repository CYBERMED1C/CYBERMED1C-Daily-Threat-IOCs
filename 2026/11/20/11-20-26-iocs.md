The two 30-day hunts use exact file hashes, hostnames, remote IPs and full URLs. Defender requires endpoint network, file and process events. A hostname-only network event cannot match a full URL, and SHA-256 is often missing from file events. Elastic requires compatible ECS fields and the full path in url.full for URL matches. DNS logs with additional labels, mobile APK/DEX contents, and memory-only or encrypted components can require separate telemetry. A connection to a reported host is an investigative lead. Both queries passed static checks and return up to 500 rows. Live platform execution was unavailable.

Recovery routes included CISA’s official catalog repository, Canada’s French advisory, the UK NCSC report feed, the Bangladesh CIRT production PDF and SafeDep’s full text appendix.
